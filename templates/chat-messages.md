# Chat message templates

Every automated message starts with 🤖 so people know it came from the sync, and goes only to the person who must act.

## New-hire thread (#onboarding, once per hire)

```
New hire: Jordan Rivera
Role: Account Executive
Team: Sales
Hiring manager: @hiring-manager
Start date: Tue, Jan 12
Location / remote: Remote
Day-1 buddy:
ATS: <link>
```

Thread reply: `@people-ops Offer signed. The onboarding project is ready: <link>. Please check the start date and owners.`

## Late-item DM (Mon–Thu, one per owner per day at most)

```
🤖 Onboarding sync:
• Jordan Rivera · Confirm laptop delivered · was due Wed, Jan 6
• Sam Patel · Provision access · was due Thu, Jan 7
Tracker: <link>
```

## Out-of-process DM (recruiting lead only)

```
🤖 Out of process:
• Executive hire Alex Chen is not in the ATS yet
• Project "Onboarding: Morgan Lee (2/2)" has no tracker row
```

## Failure DM (recruiting lead only)

```
🤖 Hiring ops failed: project tool · timeout reading tasks. Nothing was written.
```

## Hiring manager Day-1 details (posted by the manager in the thread)

```
Day-1 details for Jordan:
• First meeting: 9:30 with me (link)
• Buddy: @buddy
• Week-1 goal: shadow 3 customer calls
```
