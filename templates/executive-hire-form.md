# Executive Hire form (for leaders hiring outside the standard steps)

Leaders sometimes make direct offers with short start dates. This 2-minute form is the only thing they need to do. Recruiting backfills the ATS, and the new hire still starts with everything ready.

| Field | Type |
|---|---|
| New hire name | Short text |
| Role title | Short text |
| Team | Dropdown |
| Reports to | Short text |
| Employment type | Full-time · Part-time · Contractor |
| Location | Dropdown |
| Start date | Date |
| Offer already signed? | Yes · Not yet |
| Computer type | Dropdown |
| Anything unusual about this hire | Long text |

No pay fields: pay goes to People Ops directly, not through the form.

**Why it works:** it doesn't ask leaders to change how they hire. It asks for the five facts IT and People Ops need, at the moment the leader already has them.
