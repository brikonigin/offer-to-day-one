# Offer Request form (hiring manager → recruiting)

A short form submitted after the final debrief. **Responses are visible only to recruiting, People Ops and the approver.** Share the link inside a channel template, never as a post to the whole channel.

## Section 1: The role (copied to the onboarding project)

| Field | Type | Notes |
|---|---|---|
| Candidate name | Short text | |
| Role title | Short text | Must match the ATS job |
| Team | Dropdown | Same options as the tracker |
| Hiring manager | Short text | |
| Reports to | Short text | If different from hiring manager |
| Employment type | Full-time · Part-time · Contractor | |
| Location | Dropdown | Remote or a named office or site |
| Proposed start date | Date | Defaults to a Tuesday; see checklist rules |
| Day-1 buddy | Short text | Can be filled later |

## Section 2: Setup needs (copied to the onboarding project)

| Field | Type | Notes |
|---|---|---|
| Computer type | Dropdown | Your standard options |
| Apps and access needed | Checkboxes + other | |
| Special needs | Long text | Site badge, shift, equipment |

## Section 3: Offer details (approver only, never copied anywhere)

| Field | Type |
|---|---|
| Base pay | Number |
| Bonus / commission | Short text |
| Equity | Short text |
| Relocation or sign-on | Short text |
| Within approved band? | Yes · No (explain) |
| Anything the approver should know | Long text |

## After submit

The response emails the approver and cc's the backup. The approver replies on that one thread. Recruiting then builds the offer in the ATS.
