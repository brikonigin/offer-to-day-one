# Hiring Tracker refresh (Wednesday)

Silent: no posts, no DMs. It runs Wednesday so hiring managers see fresh notes before their Thursday update.

1. Read every Hiring Tracker row once. Skip Filled or On hold rows unless the ATS shows active candidates.
2. One ATS query: candidate **counts** by stage per open job, plus the longest time anyone has waited in their current stage. No names.
3. Pipeline snapshot (auto): `Review n · Screen n · R1 n · R2 n · Final n · Offer n · longest wait n wk`
4. Sync notes (auto), only:
   - "Not updated since <date>" when Last updated is 7+ days old
   - "Check: tracker says <Status>; ATS shows <summary>" when they clearly disagree
   - "Health suggestion: <option>" (Stalled: nobody moved in 14+ days or longest wait 6+ wk · Needs attention: longest wait 3–6 wk or scorecards owed · On track otherwise)
5. Never change Status, Next step, Blocker or Last updated.
